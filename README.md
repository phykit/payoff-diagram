# Reproduction package: "One Trade, Twelve Honest Pictures" (Kittson, 2026)

Formerly titled "The Payoff Diagram Is Lying to You"; the standfirst now opens by reversing that phrase. Manuscript v5.6, 1 November 2026, as accepted by *Wilmott* for the January 2027 issue.

Repository: https://github.com/phykit/payoff-diagram

Everything in the article that is a number or a picture is generated by the files here.

## Files
- `model.py`: pricing, the joint spot/vol model, conditional distribution, cell statistics (P(profit), E[P&L], 5% loss quantile), regime probabilities, Monte Carlo cross-check, bucket-mean alternative. Parameters at the top (`RHO = -0.60`, `NU = 0.85`, calibrated to Apple).
- `figs_v2.py`: generates `v2_fig1.pdf` to `v2_fig7.pdf` (PGF backend; needs pdflatex with mathpazo). File numbers match the article's figure numbers (`v2_fig6.pdf` is Figure 6, the three-position robustness row; `v2_fig7.pdf` is Figure 7, the 0DTE grid).
- `validate.py`: prints every number quoted in the text and compares to `expected_numbers.json`; exit code 0 on pass.
- `fetch_data.py`: downloads the seven Cboe index histories (public; the copies used for the article are in `data/`) and the Nasdaq closes for AAPL (daily) and AMZN, GOOG, GS, IBM, GLD, USO, SPY (sampled every fifth trading day) into `data/`. Nasdaq data are not redistributed here; `checksums.txt` lets you confirm you have the same series.
- `calibrate.py`: reproduces the Apple rho and nu estimates in Appendix A from `data/`.
- `calibrate_multi.py`: reproduces Table 7 (rho and nu across Apple, Amazon, Alphabet, Goldman Sachs, IBM, gold and oil; adds S&P 500 / VIX if `data/VIX_History.csv` is present).
- `robustness.py`: reproduces Table 4 (the bottom row of Figure 4 under rho = 0, a mean-reverting vol law, a physical drift, a 10% spread and the Goldman Sachs, Alphabet and gold parameters). `validate.py` imports it.
- `article_v2.tex`: the manuscript.
- `regenerate.sh`: validate, regenerate figures, typeset. One command.

## Environment
`pip install -r requirements.txt`. Python 3.11; TeX Live 2023 or later with the packages listed in `requirements.txt`.

## Order
1. `python fetch_data.py` (optional; needed only for `calibrate.py` and `calibrate_multi.py`; the model constants and the Table 4 parameters are already set).
2. `./regenerate.sh`.

## Data terms
Cboe index data are downloaded from Cboe's public endpoint under Cboe's terms of use; the seven files as downloaded on 4 September 2026 are included in `data/` for reproducibility. Nasdaq historical prices are fetched from Nasdaq's public API for personal research use and are not included in this package.
