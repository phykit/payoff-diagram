# Reproduction package: "The Payoff Diagram Is Lying to You" (Kittson, 2026)

Everything in the article that is a number or a picture is generated by the files here.

## Files
- `model.py`: pricing, the joint spot/vol model, conditional distribution, cell statistics (P(profit), E[P&L], 5% loss quantile), regime probabilities, Monte Carlo cross-check, bucket-mean alternative. Parameters at the top (`RHO = -0.60`, `NU = 0.85`, calibrated to Apple).
- `figs_v2.py`: generates `v2_fig1.pdf` to `v2_fig7.pdf` (PGF backend; needs pdflatex with mathpazo). Note: the article's Figure 6 (robustness) is file `v2_fig7.pdf` and Figure 7 (0DTE) is `v2_fig6.pdf`.
- `validate.py`: prints every number quoted in the text and compares to `expected_numbers.json`; exit code 0 on pass.
- `fetch_data.py`: downloads Cboe VXAPL (public) and Apple closes from Nasdaq's public API into `data/`. Nasdaq data are not redistributed here; `checksums.txt` lets you confirm you have the same series.
- `calibrate.py`: reproduces the rho and nu estimates in Appendix A from `data/`.
- `article_v2.tex`: the manuscript.
- `regenerate.sh`: validate, regenerate figures, typeset. One command.

## Environment
`pip install -r requirements.txt`. Python 3.11; TeX Live 2023 or later with the packages listed in `requirements.txt`.

## Order
1. `python fetch_data.py` (optional; needed only for `calibrate.py`; the model constants are already set).
2. `./regenerate.sh`.

## Data terms
Cboe index data are downloaded from Cboe's public endpoint under Cboe's terms of use. Nasdaq historical prices are fetched from Nasdaq's public API for personal research use and are not included in this package.
